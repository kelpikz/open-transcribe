# open-transcribe v0.1.1

This release reduces the wait to start dictating after you press the desktop
recording shortcut on Windows.

- Supported microphones use native Windows capture. Other devices fall back to
  ffmpeg.
- The recording indicator reuses its window as recording progresses.
- Quick releases and repeated presses cannot start a stale recording.
- Interrupted audio is reported instead of sending a clip with missing samples.
- Diagnostic checks wait until recording and transcription finish.

The microphone closes when you release the shortcut. Command line recording is
unchanged.
